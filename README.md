# CRM Ative OS - Sistema de Gestão Comercial (Squad 53)

> Sistema desenvolvido para centralizar a gestão de leads, otimizar o acompanhamento do funil de vendas e automatizar processos comerciais com inteligência.

---

## 🚀 Sobre o Projeto
O **CRM Ative OS** foi idealizado para solucionar o desafio de controle manual de leads e prospecções, oferecendo um painel moderno, responsivo e intuitivo para equipes comerciais.

## 🛠️ Tecnologias Utilizadas
* **Front-end:** React.js (Componentização, Hooks e Estilização inspirada na identidade visual da Ative).
* **Back-end:** Node.js / Arquitetura REST.
* **Banco de Dados:** PostgreSQL / Prisma ORM.
* **Controle de Versão:** Git & GitHub.

---

## 📋 Funcionalidades Principais (Épicos e Histórias de Usuário)
* **Dashboard de Visão Geral:** Métricas em tempo real sobre o total de leads mensais e taxas de conversão.
* **Gestão de Leads:** Tabela interativa com dados cadastrais, origens e status atualizados.
* **Cadastro Dinâmico:** Formulário integrado para inclusão rápida de novas oportunidades.
* **Funil de Vendas (Em desenvolvimento):** Acompanhamento visual das etapas de negociação (*Novo Lead*, *Proposta Enviada*, *Em Negociação*, *Fechado*).

---

## ⚙️ Como Executar o Projeto Localmente

### Pré-requisitos
Certifique-se de ter o **Node.js** e o **Git** instalados na sua máquina.

### 1. Clonar o Repositório
```bash
git clone https://github.com/aghata-guerra/crm-ative.git
cd crm-ative
2. Rodar o Front-end (React)
cd frontend
npm install
npm start
O projeto estará rodando localmente em http://localhost:3000.
